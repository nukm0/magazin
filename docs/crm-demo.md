# Food CRM demo

Preview: select Owner or Deputy, then Management → CRM.

Independent food fixtures demonstrate purchases, customers, frozen per-seller commissions, costs, margins, cash payment confirmation, product editing, damage/loss write-offs and expense history. Browser state uses magazin-food-crm-demo-v1 and related keys; shop data is not changed.

Preview role switching is not authentication. This client-side demonstrator contains no real customer data. Production accounting requires authenticated server APIs and persistent transactional storage.

Sample dates: October 1–20, 2026. Profit uses paid completed orders, frozen unit costs and seller commissions, expenses and inventory write-offs. Cash recovery excludes duplicate write-off deductions. Taxes/unrecorded expenses are excluded. Visits are not tracked.
